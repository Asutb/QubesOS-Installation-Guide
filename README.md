# Qubes OS Installation Guide

## 1. Pre‑Installation Checks
- Verify hardware compatibility
- Back up data
- Download ISO and verify checksum

## 2. Create Bootable USB
- Use Rufus/BalenaEtcher/dd
- ≥ 8 GB USB stick

## 3. BIOS/UEFI Setup
- Disable Secure Boot
- Enable VT‑x/AMD‑V and IOMMU/VT‑d
- Set USB as first boot device

## 4. Boot Installer
- Insert USB and restart
- Select "Install Qubes OS"

## 5. Installation Steps
- Language, keyboard, timezone
- Select target drive (⚠️ erases data)
- Configure partitions
- Set root password and user account
- Start installation

## 6. Post‑Installation Setup
- Remove USB and reboot
- Configure default qubes (sys‑net, sys‑firewall, sys‑usb)
- Update system
- Test networking and isolation

## 7. Optional Tweaks
- Install Fedora/Debian/Whonix templates
- Adjust qube memory allocation
- Enable backups
